# 공개 범위와 민감한 정보 처리

공개 대상은 Android 앱 소스, XML 리소스, 의존성 설정, Gradle Wrapper, 테스트, 리뉴얼 설명, 예시 화면 소개 이미지입니다.

두 스냅샷 모두 아래 처리를 적용한 뒤 Git 커밋을 생성했습니다.

- 운영 AdMob 앱/배너/PDF 전면광고 ID를 Google 공식 테스트 ID로 대체
- 앱 패키지/식별자를 `com.example.glucoseguard`로 변경
- 운영 서명 키, 키스토어, 비밀번호, 토큰, 서비스 계정 및 인증 설정 제외
- 개발 PC 경로가 들어 있는 로컬 설정, IDE 설정, 캐시 제외
- APK/AAB, 빌드 산출물, 실제 사용자 DB와 건강 데이터 제외
- 플레이콘솔 내부 지표, 작업 로그, 원본 백업 ZIP 제외

`scripts/check_public_sources.py`로 현재 파일과 모든 커밋에서 운영 광고 ID, 인증 문자열 패턴, 금지 파일을 검사합니다. 공식 테스트 ID와 테스트용 합성 데이터는 유지합니다.

실제 앱과 운영 설정은 원래 프로젝트에서 유지하며 이 저장소는 별도의 공개본입니다. 운영 설정은 Git에서 제외한 로컬 파일 또는 CI 비밀 변수로 관리하세요.
